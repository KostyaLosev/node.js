Simple Articles App (Node.js + Angular)

A lightweight full-stack project featuring a Node.js backend and an Angular frontend for creating, viewing, editing, and deleting simple articles.

🚀 Getting Started
1️⃣ Clone the Repository
git clone git@github.com:KostyaLosev/node.js.git
cd NodeJs-Practice

⚙️ Backend Setup
🔧 Install Dependencies
cd serverArticles
npm install

▶️ Run the Backend
npm run start


The backend will start on http://localhost:4000

💻 Frontend Setup
🔧 Install Dependencies
cd clientArticles
npm install

▶️ Run the Frontend
npm run start


The frontend will typically run on http://localhost:4200

⚡ Features

View all articles

Create new articles with WYSIWYG editor

Edit existing articles

Delete articles

Simple validation (title & content required)

📝 Notes

Articles are stored as JSON files in the backend /data folder

Minimalistic UI with Angular Signals and Quill editor

Focus on clean structure and functionality
